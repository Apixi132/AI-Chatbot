This project is meant to create a simplistic AI chatbot similar to ChatGPT or Gemini where a user asks questions and receives answers from 
the AI

A foundational component of this AI app will be HTML, CSS and JavaScript. As of the 12th of November, the HTML skeleton and CSS style pages
are partially complete but may be modified over the following days in order to add more features while the Javascript Index is in 
development.Current code in index.js is meant to select HTML elements

The files in git ignore are needed so that Git may not track environment variables, 
dynamic key-value pairs stored outside of your source code that configure how an application behaves across different settings
